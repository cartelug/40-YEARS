# 💬 07 — Voices

# Purpose

Add human dignity and lived experience without becoming a loud testimonial section.

# Main message

**The record told through lives.**

# Content blocks

- Citizen voice panels
- Teacher / student / health worker / farmer / engineer / host-community voices
- Documentary stills or silhouettes
- Short museum-style captions

# Design direction

Large cinematic quote panels, restrained portrait silhouettes, soft gold metadata, and careful editorial pacing.

# Key data

None directly; this section humanises the record.
