# 📊 03 — By the Numbers / The National Ledger

# Purpose

Make the factual proof section feel like the centre of the national record.

# Main message

**Measured progress. Real national change.**

# Content blocks

- 1986 → 2026 transformation spine
- Uganda map / national evidence wall background
- Five connected indicators
- Data plates with microcharts
- Mobile version as vertical civic ledger

# Design direction

Not a dashboard. A museum-grade civic data tableau using gold data lines, map texture, infrastructure silhouettes, and precise typography.

# Key data

- GDP/capita $330 → $986
- Electricity 60 → 2,048 MW
- Poverty 56% → 16%
- Refugees hosted 1.8M
- Stability 40 years
