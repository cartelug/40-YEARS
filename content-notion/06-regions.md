# 🗺️ 06 — The Regions

# Purpose

Show that transformation reaches across the country, not only the centre.

# Main message

**One country. Many regions. One national record.**

# Content blocks

- Uganda map with regional nodes
- Roads, power lines, schools, hospitals, agriculture, and refugee-hosting signals
- Regional evidence captions
- Mobile accordion by region

# Design direction

Regional evidence wall. Use geography as the main interface, with subtle data overlays and respectful national breadth.

# Key data

- Refugees hosted 1.8M
- 40 years of stability
